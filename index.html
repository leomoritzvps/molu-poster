molu poster

A private desktop tool that publishes molu’s own DJ set clips to molu’s TikTok, Instagram and YouTube accounts via the official platform APIs.

Supported platforms

  • YouTube – uploads Shorts via the YouTube API Services (YouTube Data API v3). YouTube Terms of Service
  • Instagram – publishes Reels via the Instagram API (Meta)
  • TikTok – publishes videos via the TikTok Content Posting API

How it works

  1. The operator signs in once with each platform (OAuth) and grants upload permission.
  2. Access tokens are stored only in the local macOS Keychain.
  3. The operator selects a finished clip and a caption; the tool uploads it to the operator’s own account.
